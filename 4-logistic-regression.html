Sınıflandırma: Lojistik Regresyon

Y'nin kendisini değil, Y'nin bir sınıfa ait olma olasılığını modelle — ve bu olasılığı hep 0 ile 1 arasında tut.

Neden lineer regresyon olmaz?

1) Kodlama sorunu. Acil serviste 3 teşhis: stroke, drug overdose, epileptic seizure. \(Y = 1, 2, 3\) diye kodlarsak sonuçlar arasında bir sıralama ve eşit mesafe varsaymış oluruz; başka bir kodlama (ör. overdose=1) tamamen farklı bir model verir. 1-2-3 kodlaması ancak doğal sıralama varsa (hafif / orta / ağır) ve aralar eşitse mantıklı olurdu.

2) Olasılık aralık dışı. İki sınıfta 0/1 kodlayıp lineer regresyon yaparsak \(\hat Y\)'yi \(P(Y=1\mid X)\) gibi okuyabiliriz ama bazı tahminler 0'ın altına veya 1'in üstüne çıkar — olasılık olarak anlamsız.

Lineer vs Lojistik: Default verisi

Kredi kartı bakiyesi (balance) → temerrüt (default = 1). Lineer regresyon (kesikli) negatif "olasılıklar" üretiyor; lojistik (yeşil) her zaman [0,1] arasında S eğrisi.

Lojistik model

$$p(X) = P(Y=1\mid X) = \frac{e^{\beta_0+\beta_1X}}{1+e^{\beta_0+\beta_1X}} = \frac{1}{1+e^{-(\beta_0+\beta_1X)}}$$

Bu logistic (sigmoid) fonksiyon X ne olursa olsun S şeklinde bir eğri üretir ve çıktı her zaman 0–1 arasındadır.

Odds ve log-odds (logit)

$$\underbrace{\frac{p(X)}{1-p(X)}}_{\text{odds}} = e^{\beta_0+\beta_1X} \qquad\Longrightarrow\qquad \underbrace{\log\!\left(\frac{p(X)}{1-p(X)}\right)}_{\text{log-odds / logit}} = \beta_0+\beta_1X$$
  • Odds 0 ile ∞ arasında. Ör. p = 0.2 → odds = 0.2/0.8 = 1/4 (5 kişiden 1'i temerrüde düşer). p = 0.9 → odds = 9.
  • Lojistik regresyonda log-odds X'e göre lineerdir.
  • Yorum: X 1 birim artınca log-odds \(\beta_1\) kadar artar ⇔ odds \(e^{\beta_1}\) katına çıkar. p(X)'teki değişim ise X'in o anki değerine bağlıdır (eğri lineer değil). \(\beta_1>0\) → X artınca p artar.

β₀ ve β₁ ile oyna

β₁ eğrinin dikliğini (ve yönünü), β₀ eğrinin konumunu belirler. Karar sınırı p = 0.5 ⇔ \(x = -\beta_0/\beta_1\). "MLE ile fit et" maksimum olabilirlik çözümüne animasyonla gider.

Katsayıları tahmin etmek: Maximum Likelihood

Lineer regresyondaki gibi least squares kullanılabilirdi ama maximum likelihood daha iyi istatistiksel özelliklere sahip. Sezgi: öyle \(\beta_0,\beta_1\) bul ki temerrüde düşenler için \(\hat p(x_i)\) 1'e, düşmeyenler için 0'a mümkün olduğunca yakın olsun.

$$\ell(\beta_0,\beta_1) = \prod_{i:\,y_i=1} p(x_i)\prod_{i':\,y_{i'}=0}\big(1-p(x_{i'})\big)$$ $$\log \ell = \sum_{i=1}^n \Big[y_i\log p(x_i) + (1-y_i)\log\big(1-p(x_i)\big)\Big]$$

Kapalı form çözüm yok → iteratif sayısal yöntemlerle (gradient ascent, Newton-Raphson) çözülür. Log-likelihood'un negatifi = log loss / cross-entropy.

ROC eğrisi ve AUC

ROC (receiver operating characteristics) eğrisi, tüm olası eşikler için iki hata türünü aynı anda gösterir: x ekseni FPR (1 − specificity), y ekseni TPR (sensitivity).

  • İdeal ROC eğrisi sol üst köşeyi sarar.
  • Tüm eşikler üzerinden özet performans: AUC (area under the curve). Büyük AUC = daha iyi classifier.
  • AUC = 0.5 → köşegen, yazı-tura kadar iyi. AUC = 1 → mükemmel.

Çok sınıflı (multi-class) sınıflandırma

Sınıf sayısı K > 2 ise iki yaygın yaklaşım:

  • One-vs-Rest (OvR): her sınıf için "bu sınıf mı, değil mi?" ikili lojistik model kur (K model); en yüksek olasılığı veren sınıfı seç.
  • Multinomial (softmax): tek model, bir sınıf baseline: $$P(Y=k\mid X=x) = \frac{e^{\beta_{k0}+\beta_{k1}x_1+\dots+\beta_{kp}x_p}}{\sum_{l=1}^{K} e^{\beta_{l0}+\beta_{l1}x_1+\dots+\beta_{lp}x_p}}$$

Lineer olmayan karar sınırları

Lojistik regresyonun karar sınırı \(\beta_0+\beta_1x_1+\beta_2x_2 = 0\) → lineer. Ama polinom regresyondaki hileyle \(x_1^2, x_2^2, x_1x_2\) gibi dönüştürülmüş özellikler eklersek sınır eğri olur (model katsayılarda hâlâ lineer).

Polinom özelliklerle eğri karar sınırı

Halka şeklindeki veride düz bir çizgi işe yaramaz. Dereceyi 2'ye çıkar ve modeli eğit (gradient ascent ile canlı).

Scikit-learn: fit, olasılık, tahmin 
import pandas as pd
import numpy as np
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split

df = pd.read_csv("Default.csv")
df["default01"] = (df["default"] == "Yes").astype(int)
df["student01"] = (df["student"] == "Yes").astype(int)   # dummy

X = df[["balance", "income", "student01"]]
y = df["default01"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=1, stratify=y)

# DİKKAT: sklearn varsayılan olarak L2 regularization uygular (C=1.0).
# Ders tablolarıyla (MLE) aynı katsayılar için regularization'ı kapat:
# C çok büyük (eski sürümlerde penalty=None da olur)
logit = LogisticRegression(C=1e10, max_iter=1000).fit(X_train, y_train)
print(logit.intercept_, logit.coef_)

p = logit.predict_proba(X_test)[:, 1]     # P(Y=1 | X)  -> 2. sütun!
y_hat_05 = logit.predict(X_test)          # eşik 0.5
y_hat_02 = (p > 0.2).astype(int)          # eşik 0.2 (elle)
Confusion matrix, metrikler, ROC & AUC 
from sklearn.metrics import (confusion_matrix, classification_report,
                             accuracy_score, recall_score, precision_score,
                             roc_curve, roc_auc_score, ConfusionMatrixDisplay)
import matplotlib.pyplot as plt

cm = confusion_matrix(y_test, y_hat_02)   # satırlar = GERÇEK, sütunlar = TAHMİN (sklearn!)
tn, fp, fn, tp = cm.ravel()
print(cm)
print("Sensitivity:", tp / (tp + fn), " Specificity:", tn / (tn + fp))
print(classification_report(y_test, y_hat_02))

fpr, tpr, thresholds = roc_curve(y_test, p)
print("AUC:", roc_auc_score(y_test, p))
plt.plot(fpr, tpr); plt.plot([0, 1], [0, 1], "--")
plt.xlabel("False positive rate"); plt.ylabel("True positive rate"); plt.show()
