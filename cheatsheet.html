Temel kavramlar

\(Y = f(X)+\varepsilon\) · Prediction (doğru \(\hat Y\)) vs Inference (ilişkiyi anlamak)
\(E(Y-\hat Y)^2 = [f-\hat f]^2 + \operatorname{Var}(\varepsilon)\) → reducible + irreducible
Regression: nicel Y · Classification: nitel Y
Supervised: \(y_i\) var · Unsupervised: \(y_i\) yok
Esneklik ↑ → train MSE ↓ hep, test MSE U şekli
Test MSE = Var(\(\hat f\)) + Bias² + Var(ε)

Basit lineer regresyon

$$\hat\beta_1=\frac{\sum(x_i-\bar x)(y_i-\bar y)}{\sum(x_i-\bar x)^2},\ \hat\beta_0=\bar y-\hat\beta_1\bar x$$ RSS \(=\sum e_i^2\) · RSE \(=\sqrt{\text{RSS}/(n-2)}\)
\(R^2 = 1-\text{RSS}/\text{TSS}\), TSS \(=\sum(y_i-\bar y)^2\); SLR'de \(R^2=r^2\)
SE(\(\hat\beta_1)^2=\sigma^2/\sum(x_i-\bar x)^2\) · %95 GA: \(\hat\beta_1\pm2\,\text{SE}\)
\(t=\hat\beta_1/\text{SE}(\hat\beta_1)\), \(H_0:\beta_1=0\)

Gradient descent

\(\partial\text{SSE}/\partial\beta_0=-2\sum(y_i-\hat y_i)\)
\(\partial\text{SSE}/\partial\beta_1=-2\sum x_i(y_i-\hat y_i)\)
\(\beta\leftarrow\beta-\alpha\nabla\) · α büyük → ıraksar, küçük → yavaş
Adımlar: başlat → SSE → gradyan → güncelle → tekrar

Çoklu regresyon

\(\hat{\boldsymbol\beta}=(\mathbf X^\top\mathbf X)^{-1}\mathbf X^\top\mathbf y\)
\(\beta_j\): diğerleri sabitken X_j +1 → Y'deki ort. değişim
Advertising: 2.939 + 0.046 TV + 0.189 radio − 0.001 news
\(F=\frac{(\text{TSS}-\text{RSS})/p}{\text{RSS}/(n-p-1)}\)
k seviye → k−1 dummy · \(X^2\) eklemek = hâlâ lineer model

Diğer metrikler

MSE \(=\frac1n\sum(y-\hat y)^2\) · RMSE \(=\sqrt{\text{MSE}}\)
MAE \(=\frac1n\sum|y-\hat y|\) · MAPE \(=\frac{100}{n}\sum|\frac{y-\hat y}{y}|\)
Error rate \(=\frac1n\sum I(y_i\ne\hat y_i)\)

Olasılık

\(P(A|B)=P(A\cap B)/P(B)\)
Toplam: \(P(B)=\sum_i P(A_i)P(B|A_i)\)
Bayes: \(P(A_i|B)=\dfrac{P(A_i)P(B|A_i)}{\sum_k P(A_k)P(B|A_k)}\)
Satranç: P(W)=0.375, P(T₁|W)=0.4

Bayes classifier & Naive Bayes

Optimal: \(\arg\max_j P(Y=j|X=x_0)\) → en düşük hata (Bayes error), ama P(Y|X) bilinmez
NB: \(\hat y=\arg\max_k \pi_k\prod_j P(x_j|Y=k)\) (koşullu bağımsızlık)
\(\hat\pi_k=n_k/n\) · kategorik: sayım/n_k · sayısal: Gaussian (μ, σ²)
Laplace: (sayı+1)/(n_k + #değer)

KNN

\(P(Y=j|X=x_0)=\frac1K\sum_{i\in\mathcal N_0}I(y_i=j)\)
K=1: train hata 0, pürüzlü sınır, overfit · K büyük: düz sınır, underfit
Esneklik ~ 1/K · Uzaklık tabanlı → ölçekle (StandardScaler)

Lojistik regresyon

\(p(X)=\dfrac{e^{\beta_0+\beta_1X}}{1+e^{\beta_0+\beta_1X}}\) · odds \(=p/(1-p)=e^{\beta_0+\beta_1X}\)
log-odds lineer · X +1 → odds × \(e^{\beta_1}\)
MLE: \(\max \sum[y\log p+(1-y)\log(1-p)]\), kapalı form yok
Default: −10.6513 + 0.0055·balance → p(1000)=0.00576, p(2000)=0.586
Student: tek başına +0.40, çoklu modelde −0.65 (confounding)

Confusion matrix

Sensitivity = TPR = Recall = TP/P · Specificity = TN/N
FPR = FP/N = 1 − spec (Type I) · FNR = FN/P (Type II)
Precision = TP/(TP+FP) · Accuracy = (TP+TN)/n
Default @0.5: 252/333 = %75.7 kaçırıldı, hata %2.75
Default @0.2: 138/333 = %41.4 kaçırıldı, hata %3.73
Eşik ↓ → sensitivity ↑, specificity ↓

ROC / AUC

x: FPR, y: TPR, tüm eşikler · ideal: sol üst köşe
AUC=1 mükemmel, 0.5 rastgele
